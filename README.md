# Video Downloader PWA

Aplicación Web Progresiva de alto rendimiento diseñada para la descarga eficiente de contenido multimedia.

## 🚀 Overview
Una herramienta multiplataforma construida con las últimas tecnologías web, permitiendo a los usuarios descargar videos de múltiples fuentes con una experiencia de aplicación nativa.

## ✨ Key Achievements
- **Next.js 16 & Tailwind v4**: Uso pionero de las versiones más recientes de frameworks para máxima eficiencia de desarrollo.
- **Procesamiento con Web Workers**: Descargas y procesamiento de archivos en hilos separados para mantener la fluidez de la UI.
- **Experiencia PWA**: Soporte offline, caching agresivo y diseño Mobile-First con animaciones fluidas.

## 🛠️ Technologies
- TypeScript / Next.js 16
- Tailwind CSS v4
- Framer Motion
- Web Workers / Service Workers

## 📦 Features
- Instalable como aplicación nativa (PWA).
- Procesamiento paralelo de descargas.
- Interfaz obsidian-style minimalista.
